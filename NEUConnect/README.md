# NEU 校园网自动连接

`NEU_connect.zip` 是免 Python 版 NEUConnect 程序的相关 Python 源码。如果电脑已有 Python 环境，可以优先使用这个版本。需要安装 Playwright 和 Microsoft Edge，具体步骤见压缩包里的 README。

源码版在 `neu_connect.py` 中填写账号密码；免 Python 版使用 `config.json`。源码压缩包中的账号密码为空，请不要分享填有自己密码的文件。

程序连接已保存的 NEU Wi-Fi，并打开校园网认证页面。如果页面需要验证码或其他验证，请手动完成。页面显示“网络已连接”才表示认证成功。
